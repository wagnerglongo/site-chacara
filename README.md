# Chácara Nossa Senhora Aparecida

Site de divulgação e reserva de uma chácara para aluguel de fim de semana: apresentação da área de lazer, galeria de fotos, valores e contato.

**🔗 Demo:** https://site-chacara-tau.vercel.app

## Destaques

- Página única, responsiva, pensada para quem abre pelo celular
- Galeria de fotos da área de lazer
- Bloco de preço e chamada para contato
- Publicado na Vercel

## Tecnologias

HTML5 · CSS3 · JavaScript

## Rodando localmente

```bash
git clone https://github.com/wagnerglongo/site-chacara.git
cd site-chacara
# abra o index.html no navegador ou use um servidor local:
npx serve .
```
